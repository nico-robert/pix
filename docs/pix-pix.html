toB64 [::pix]Top, Main, Index

Converts an img or ctx object into a base64-encoded string.

toB64 object
Parameters
objectimg or ctx object handle.
Description

Note: On the Nim side, the base64 module is considered unstable. It is recommended to use the toBinary command combined with Tcl's native binary encode base64 command instead.

Return value
